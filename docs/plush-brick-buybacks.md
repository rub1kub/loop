# Журнал выкупов PLUSH BRICK

LOOP заявляет, что часть дохода направляется на выкуп PLUSH BRICK с рынка. Заявление без
проверяемых сделок — это обещание, а не факт, поэтому каждый выкуп записывается сюда с хешом
транзакции, который можно открыть в обозревателе.

| Поле                | Значение                                           |
| ------------------- | -------------------------------------------------- |
| Статус              | журнал заведён, сделок пока нет                    |
| Механизм            | ручной выкуп казначейством, автоматизации нет      |
| Сеть                | TON mainnet `-239`                                 |
| Токен               | `EQAJ40p3zlCoomgANMQ4u5eIktLMZtWP87GGKDKlyW_EZBwt` |
| Казначейство выкупа | адрес указывается при первой сделке                |

## Правила записи

1. Запись появляется **после** подтверждения транзакции в mainnet, а не при намерении.
2. Хеш обязателен и должен открываться в обозревателе. Строка без хеша не считается выкупом.
3. Указывается фактически потраченная сумма и фактически полученное количество токенов, без
   округления в выгодную сторону.
4. Записи не удаляются и не переписываются. Ошибка исправляется новой строкой с пометкой.
5. Купленные токены не участвуют в определении статуса holder: собственный выкуп не должен
   влиять на комиссию.

## Что этот журнал не обещает

- Периодичность. Выкуп ручной, расписания нет.
- Долю дохода. Фиксированного процента нет, пока он не объявлен отдельно.
- Влияние на цену. Запись доказывает сделку, а не результат.
