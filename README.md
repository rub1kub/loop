# LOOP

LOOP — открытое социальное приложение в Telegram на базе TON. В BANK участники занимают место в очереди, в DUEL начинают вызов с равных шансов, а в командах соревнуются подтверждённой активностью. Приложение не хранит средства: действия с GRAM подтверждаются во внешнем кошельке, а результат можно проверить в блокчейне.

**Открытие — 5 августа 2026, 19:30 МСК.** Вход уже открыт: до открытия приложение показывает таймер, персональную реферальную ссылку и гонку приглашений. Пригласивший получает 2% с каждого подтверждённого взноса приглашённых — навсегда, из комиссии протокола. В момент открытия доступ включается автоматически по часам сервера.

[Открыть в Telegram](https://t.me/getloopbot?startapp) · [Посмотреть сайт](https://app.tonsuite.org) · [Исходный код](https://github.com/rub1kub/loop)

> LOOP работает в основной сети TON с настоящими GRAM. BANK — финансовая пирамида, и проект называет её так прямо: выплаты зависят от новых участников и могут остановиться.

## Как работает LOOP

### BANK

Пользователь выбирает сумму и цель — 1,25×, 1,5× или 2× — и занимает место в очереди. Новые взносы сначала наполняют более ранние позиции. Когда выбранная цель достигнута, контракт сам отправляет выплату.

Чтобы первые участники не могли сразу занять очередь слишком крупными суммами, BANK начинает с лимита 1 GRAM, и потолок растёт только за реальные выплаты: ступень в N GRAM открывается после 5×N завершённых позиций. Лестница — 1, 2, 3, 5, 7, 10, 15, 20, 30, 50, 75 и 100 GRAM; выше 100 GRAM потолок не поднимается. Комиссия — 10% со взноса.

Очередь движется только пока появляются новые позиции. Отменить подтверждённую позицию или забрать взнос раньше срока нельзя.

### DUEL

Можно позвать друга или найти соперника автоматически. Оба участника начинают с одинаковой суммы и шанса 50/50. После появления пары открывается минута: любой игрок может подтвердить дополнительный взнос и увеличить свою долю пула, а значит и шанс. Каждое позднее пополнение даёт ещё 20 секунд на ответ, но вся фаза ограничена тремя минутами и диапазоном 90/10.

Устройство каждого игрока заранее фиксирует скрытое значение. Раскрыть его можно только после окончания фазы усиления. Контракт определяет победителя пропорционально подтверждённым долям; сервер LOOP не может изменить ни взносы, ни шанс, ни результат.

Если один участник вовремя раскрывает своё значение, а второй нет, побеждает первый. Если этого не делает никто, контракт возвращает обоим их взносы. Контракт удерживает комиссию 10% с завершённого дуэля; держатели PLUSH BRICK освобождены от неё полностью.

### Рейтинг

Рейтинг обновляется каждый месяц и показывает не размер кошелька, а надёжность участника. Очки начисляются за подтверждённые выплаты BANK, завершённые дуэли, своевременные действия и приглашённых друзей хотя бы с одной подтверждённой операцией. Суммы, прибыль, победы и поражения на место не влияют.

### Команды

Команды соревнуются недельными сезонами. Основной счёт — сумма подтверждённых взносов участников в BANK за неделю; выплаты и DUEL видны отдельно и не подменяют этот показатель. Владелец настраивает название, описание, эмблему, режим вступления и роли. Число участников не ограничено, но каждый человек одновременно состоит только в одной команде.

Профиль также собирает историю BANK и DUEL, статус PLUSH BRICK и подтверждения операций в одном месте. Держателям PLUSH BRICK LOOP не начисляет комиссию вовсе; запланированы откупы токена с рынка. ## Открытый проект

Исходники интерфейса, бота, API, контрактов и тестов доступны в этом репозитории. Можно проверить правила, собрать свою версию или предложить изменение. Проект распространяется по лицензии MIT.

Финансовый результат определяют контракты, а не интерфейс и не ответы сервера. История, очередь и рейтинг меняются только после подтверждения операции в TON.

Опубликованные контракты основной сети (исходники проверены на verifier.ton.org — байткод в сети совпадает с кодом в репозитории):

## Архитектура

```text
Обычный браузер ───────────────────────────► Статический лендинг

Telegram ─► Mini App ── Telegram initData ─┐
                                          ├─► FastAPI + aiogram ─┬─► PostgreSQL
Владелец ─► /control ── TON-подтверждение ─┘                     └─► Redis

Mini App или /control ─► внешний кошелёк ─► Основная сеть TON
                                             ├── BankQueue
                                             └── DuelEscrow
                                                      │
                                                      ▼
                                         Обработчик операций TON
                                                      │
                                                      ▼
                                                 PostgreSQL
                                                      │
                                                      ▼
                                     Доставщик карточек ─► Telegram
```

Обычный браузер получает только лендинг и не запускает Telegram, TON Connect или API продукта. PostgreSQL хранит данные приложения и подтверждённую историю, Redis — временные блокировки и ограничения частоты запросов. BANK и DUEL разделены на уровне API, таблиц, событий и контрактов.

## Быстрый запуск

Нужны Node.js 22+, Python 3.12+, Docker и Acton 1.0. Команда `make setup` вызывает `python3`, поэтому этот исполняемый файл должен вести на Python 3.12 или новее.

```bash
cp .env.example .env
make setup
```

Запуск интерфейса с локальной имитацией Telegram:

```bash
VITE_MOCK_TELEGRAM=true make dev
```

В этом режиме нет настоящей авторизации, подписи транзакций и отправки средств.

Запуск PostgreSQL, Redis, API, обработчика TON и доставщика карточек:

```bash
cp .env.example .env.production
make docker-up
```

Все параметры окружения и варианты запуска описаны в [docs/setup.md](docs/setup.md).

## Проверки

Основные проверки проекта:

```bash
make lint
make typecheck
make test
make test-e2e
make test-security
```

Локальная сборка и тесты контрактов:

```bash
make contracts-build
make contracts-test
```

Строгий технический профиль перед основной сетью:

```bash
make contracts-mainnet-technical
```

Пакет исходников и доказательств для независимого аудита:

```bash
make contracts-audit-pack
```

После получения отчёта, заполнения `deployments/mainnet/release.json` и
подготовки mainnet-контрактов:

```bash
make contracts-mainnet-preflight
```

Preflight работает по принципу fail-closed: без проверяемого отчёта аудита,
совпадающего коммита, лимитов и сетевых доказательств выпуск не разрешается.

Проверка кода и состояния опубликованных контрактов:

```bash
make contracts-verify
make contracts-inspect
```

Полный список команд доступен через `make help`, а границы наборов тестов описаны в [docs/testing.md](docs/testing.md).

## Развёртывание

Рабочая версия загружается прямо на VPS по SSH. GitHub Actions в выпуске не участвует.

```bash
npm run deploy:vps
```

Если менялись только сайт или Mini App, используется отдельный выпуск без перезапуска серверных сервисов:

```bash
npm run deploy:vps:web
```

Полный выпуск создаёт резервную копию, применяет миграции, запускает сервисы и проверяет их состояние. Подробности и порядок возврата к предыдущей версии описаны в инструкции.

Подробная инструкция: [docs/deployment.md](docs/deployment.md).

## Ограничения и безопасность

- BANK не создаёт доход сам по себе. Без новых позиций выплаты останавливаются на неопределённый срок.
- Подтверждённую позицию BANK нельзя отменить или вернуть раньше достижения цели.
- В DUEL можно потерять весь подтверждённый взнос, включая усиления. Комиссия контракта — 10% от общего пула завершённой игры; держатели PLUSH BRICK от неё освобождены.
- Контракты BANK и DUEL работают в основной сети TON с настоящими GRAM.
- LOOP не получает секретные фразы или закрытые ключи пользователей и не ведёт внутренний пользовательский баланс.

Подробнее о границах доверия и сообщении об уязвимостях: [docs/security.md](docs/security.md) и [SECURITY.md](SECURITY.md).
